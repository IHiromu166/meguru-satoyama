# 巡る里山

デッキの循環が、そのまま生態系の物質循環になっているソロ用デッキ構築ゲーム。

## 企画概要

デッキ構築ゲームのカードの巡り方と、生態系のエネルギーの巡り方は同じ形をしている。
山札は土壌、手札は発芽、場は生育、**捨て札は死骸**、そしてシャッフルは分解にあたる。

この対応が決まると残りが自動的に決まる。捨て札を山札に戻すカードは文字通り分解者であり、
デッキを速く回すカードは物質循環を速める生物になる。
「生態系が綺麗ならデッキが回る」がテーマではなく実装そのものになる。

外来種はこの循環を内側から詰まらせる。しかも1種ずつ壊す場所が違うため、
プレイヤーの仕事は「今どこが詰まっているかを診断して対処する」ことになる。
20ターンを生き延び、最終的な生態系の形を得点として競う。

### 中核ルール

> 消費者をプレイするとき、場または手札から捕食対象を1枚選び、捨て札に送る。
> 食べられなければ飢餓となり、場には出るが何も起きない。

比率のルールを一行も書いていないのに、この判定だけで栄養段階のピラミッドが
最適解として現れる。5枚の手札に捕食者と獲物を同時に揃えるには、
獲物のほうがデッキに多く入っていなければならないため。
強いカードを集めることと生態系を整えることが対立するのが、このゲームの中心的な緊張になる。

### 駆除のジレンマ

外来種への対処には二つの道がある。人間による駆除は即効性があるが、
駆除カード自体は生態系の一員ではなく、持ちすぎればデッキが薄まり得点も下がる。
在来天敵による抑制は遅く仕込みが要るが、デッキを汚さず生態系はむしろ強くなる。

手っ取り早い解決と綺麗な解決が別ルートとして両立し、後者のほうが最終的に強い。

## 仕様

| 項目 | 内容 |
| --- | --- |
| 形式 | 1人用 / 20ターン耐久 + 最終スコア |

## PWA

対応ブラウザでは、メニューの「アプリをインストール」からホーム画面へ追加できます。
初回の読み込み後は、ゲーム本体のファイルを端末に保存するため、オフラインでも起動できます。
更新を反映するには、オンラインで一度ページを再読み込みしてください。
