# 巡る里山 — ゲーム設計書

ソロ用デッキ構築ゲーム。デッキの循環が、そのまま生態系の物質循環になっている。

- **形式**: 1人用 / 20ターン耐久 + 最終スコア
- **プラットフォーム**: ブラウザ (Vite + TypeScript)。Electron 化は任意で最終日
- **制作期間**: 7日
- **企画版**: https://claude.ai/code/artifact/125944b3-7a49-4828-9190-79c49bf5246c

実装の型定義・モジュール構成は [ARCHITECTURE.md](./ARCHITECTURE.md)、
カードの数値は [CARDS.md](./CARDS.md)、作業分担は [TASKS.md](./TASKS.md) を参照。

---

## 1. 中核となる発想

デッキ構築ゲームのカードの巡り方と、生態系のエネルギーの巡り方は同じ形をしている。

| デッキ | 生態系 |
| --- | --- |
| 山札 | 土壌 |
| 手札 | 発芽 |
| 場 | 生育 |
| 捨て札 | **死骸** |
| シャッフル | 分解 |

この対応が決まると残りが自動的に決まる。捨て札を山札に戻すカードは文字通り分解者であり、
デッキを速く回すカードは物質循環を速める生物になる。
「生態系が綺麗ならデッキが回る」がテーマではなく実装そのものになる。

---

## 2. 中核ルール: 捕食判定

> **消費者をプレイするとき、場または手札から捕食対象を1枚選び、捨て札に送る。
> 食べられれば効果が発動し、食べられなければ飢餓となり、場には出るが何も起きない。**

捕食対象は「自分の栄養段階 - 1」のカード。比率のルールを一行も書いていないのに、
この判定だけでピラミッド型が最適解として現れる。5枚の手札に捕食者と獲物を同時に
揃えるには、獲物のほうがデッキに多く入っていなければならないため。

### 確定した裁定

以下は実装時に迷う箇所。**この通りに実装すること。** 変更したい場合は勝手に変えず提案する。

1. **飢餓のカードも場に出る。** 効果は発動しないが、場には存在する
   (生物はいるが機能していない状態)。ターン終了時に他と同じく捨て札へ。
2. **場から捕食した場合、その獲物がすでに発揮した効果は取り消さない。**
   生産者を出してエネルギーを得たあと、その生産者を食べてよい。
   *理由*: 栄養段階を上げるたびに手札スロットを1枚消費することが本質的なコストであり、
   二重にペナルティを課すとデッキが硬直して回らなくなる。
3. **捕食対象が複数ある場合はプレイヤーが選ぶ。** 自動選択はしない。
4. **分解者 (段階0) は獲物にならない。** 段階1の生産者は捕食しないため、
   「段階0を食べる」状況は発生しない。
5. **外来種は原則として獲物にならない。** 例外は `eatsInvasive` を持つ在来種のみ (→ 第6節)。
6. **行動回数の制限は設けない。** 手札は全部プレイしてよい。
   獲物を必要とすることが実質的な制限として働くため、二重の制限は不要。

## 3. カードの種別

| 種別 | 段階 | 役割 | 捕食 |
| --- | --- | --- | --- |
| 生産者 | 1 | エネルギー産出 | 不要 |
| 一次消費者 | 2 | ドロー・獲得回数 | 段階1を1枚 |
| 二次消費者 | 3 | 強力な効果 | 段階2を1枚 |
| 頂点捕食者 | 4 | 決め手・得点源 | 段階3を1枚 |
| 分解者 | 0 | 捨て札 → 山札 | 不要 |
| 人間の介入 | — | 外来種の廃棄 | 不要 |
| 外来種 | — | 妨害 | プレイ不可 |

### 初期デッキ

**ススキ ×7 + ミミズ ×3** の10枚。消費者が1枚もない、植物と分解者だけの
最小の循環から始まる。プレイヤーの仕事は、この裸地の上に食物連鎖を積み上げること。

---

## 4. ターンの流れ

各ターンは4フェイズ。フェイズは一方向にしか進まない。

### 4.1 メインフェイズ (`main`)

手札を **任意の順で** プレイする。順番が自由なので、連鎖の組み方がプレイヤーの腕になる。

- **生産者**: 場に出て `energy` を加算する。
- **消費者**: 捕食対象を1枚選んで捨て札に送り、効果を解決する。対象がなければ飢餓。
- **分解者**: 場に出て効果を解決する (捕食不要)。
- **人間の介入**: 場に出て効果を解決する (捕食不要)。
- **外来種**: **プレイできない。** 手札に留まり、常在効果を発揮し続ける。

### 4.2 獲得フェイズ (`gain`)

蓄えたエネルギーを支払い、供給から在来種カードを獲得して **捨て札** に置く。
獲得回数は基本1回 (`gainsLeft`)。効果で増える。エネルギーはターンをまたいで持ち越さない。

### 4.3 侵入フェイズ (`invasion`)

1. **侵入**: 侵入スケジュール (→ 第5節) に従って外来種が捨て札に加わる。
2. **増殖**: **手札に残っている外来種** 1枚につき、同じ外来種を1枚捨て札に加える。
   外来種の山が尽きている場合は増えない。

> 増殖の判定を「場」ではなく「手札」で行うのは、外来種がプレイ不可で場に出ないため。
> 手札に抱えるほど増える構造になり、引いてしまうこと自体が罰になる。

### 4.4 クリーンアップ (`cleanup`)

先に手札の外来種の `eatConsumer` (→ 第5節) を解決してから、
場と手札をすべて捨て札に送り、5枚引く。
山札が尽きたら捨て札をシャッフルして山札にする (シャッフル = 分解)。

その後、敗北判定 (→ 第5節) を行い、20ターン終了なら結果画面へ。

## 5. 外来種

外来種を単なる重りにしないことが肝。**壊し方を1種ずつ変える**ことで、
プレイヤーの仕事が「今どこが詰まっているかを診断して対処する」に変わり、
毎回のランが違う問題になる。

| 種 | 攻撃する箇所 | 常在効果 | 在来天敵 |
| --- | --- | --- | --- |
| セイタカアワダチソウ | 基盤 | 生産者のエネルギー産出 −1 | なし |
| アメリカザリガニ | 循環 | 分解者の効果を無効化 | サギ |
| オオクチバス | 中間層 | クリーンアップ時に段階2を1枚廃棄 | なし |
| ウシガエル | 密度 | 増殖時に追加で1枚増える | サギ |
| アライグマ | 広域 | 生産者 −1 かつ 段階2を1枚廃棄 | ツキノワグマ |

### 常在効果の範囲

**外来種の常在効果は、そのカードが手札にある間だけ働く。**
山札や捨て札にあるときは何もしない。デッキに占める割合が増えるほど手札に来やすくなり、
痛みが自然に比例する。

### `eatConsumer` — 外来種による捕食

オオクチバスとアライグマは、クリーンアップ時に該当段階の在来消費者を1枚**捕食**する。

- **捕食対象は 場・手札・捨て札 のいずれからでも選べる。** 山札と廃棄済みは対象外。
- **捕食されたカードは捨て札ではなく廃棄 (`trash`) される。** デッキから永久に失われ、
  得点計算にも数えられない。
- 候補が複数あるときは **場 → 手札 → 捨て札** の順に探し、各ゾーンの先頭から1枚を取る。
  プレイヤーの選択は挟まない (外来種の側の行動なので自動処理)。
- 候補が1枚もなければ何も起こらない。

> 捨て札へ送るだけでは、直後に場と手札がまとめて捨て札へ行くため差が出ない。
> **廃棄** して初めて「中間層を削る」攻撃として成立する。捨て札まで対象に含めるのは、
> 場に何も出していないターンでも、外来種を手札に抱えた代償を必ず払わせるため。

### 増殖の上限

各外来種には供給の山と同じく **有限の枚数** を用意する (→ [CARDS.md](./CARDS.md))。
山が尽きたらそれ以上は増えない。これがないと指数的に増えて勝ち筋が消える。

### 侵入スケジュール

| ターン | 1ターンあたりの侵入 | 解禁される種 |
| --- | --- | --- |
| 1–3 | 0 | — |
| 4–8 | 0.5 (2ターンに1枚) | セイタカアワダチソウ / ウシガエル |
| 9–14 | 1 | + アメリカザリガニ |
| 15–20 | 1 | + オオクチバス / アライグマ |

侵入する種は解禁済みの中からランダムに選ぶ (山が残っているものに限る)。
`0.5` はカウンタに加算して1.0を超えたら1枚侵入させる方式で実装する。

### 敗北条件

**全ゾーン (山札 + 手札 + 場 + 捨て札) の過半数が外来種になった時点で即敗北。**
廃棄済みのカードは数えない。増殖を放置すると急激に悪化するため、
対処の先送りが直接の死につながる。

## 6. 駆除のジレンマ

外来種への対処には二つの道があり、このゲームはどちらを選ぶかについて立場を取る。

- **人間による駆除** (`control` カード) — 即効性があり確実だが、
  駆除カード自体は生態系の一員ではない。持ちすぎればデッキは薄まり、
  最終スコアの「介入の痕跡」でも減点される。
- **在来天敵による抑制** (`eatsInvasive`) — 特定の在来種が特定の外来種を捕食できる。
  遅く、事前の仕込みが要るが、デッキを汚さず、むしろ生態系が強くなる。

手っ取り早い解決と綺麗な解決が別ルートとして両立し、後者のほうが最終的に強い。
**アライグマだけは在来天敵がツキノワグマ (コスト7) しかなく、実質的に人間の介入が必要**
という難度の傾斜をつけてある。

### 在来天敵による捕食の扱い

`eatsInvasive` を持つ在来種は、通常の捕食対象の代わりに、
**手札にある該当の外来種を捕食できる**。この場合、外来種は捨て札ではなく
**廃棄 (trash)** される。効果は通常どおり発動する。

## 7. 得点

20ターンを生き延びた時点でデッキ全体 (山札 + 手札 + 場 + 捨て札) を評価する。
**数値はすべて調整前の初期値。** Day 6 で必ず動かす。

| 評価項目 | 内容 | 点 |
| --- | --- | --- |
| 多様性 | デッキ内の在来種の**種類数** | ×2 |
| ピラミッド適合 | 段階 n の枚数 < 段階 n−1 の枚数 を満たす n ごとに | +5 |
| 循環効率 | 分解者がデッキ全体の 10–20% に収まっている | +10 |
| 頂点の定着 | 段階4のカードが1枚以上あり、段階3の枚数がそれ以上 | +15 |
| 残存外来種 | デッキに残った外来種1枚につき | −5 |
| 介入の痕跡 | デッキに残った `control` カード1枚につき | −1 |

敗北 (生態系崩壊) で終わった場合はスコア0とし、崩壊したターン数のみ記録する。

## 8. v1 のスコープ

期間を守る唯一の方法は、最初から何を作らないか決めておくこと。

### 作る

- 在来種カード 22種 + 駆除カード 3種 + 外来種 5種
- 捕食判定と飢餓
- 20ターンの耐久ループ、侵入スケジュール、敗北判定
- 食物網 / ピラミッドの常時 SVG 可視化
- 最終スコア画面
- シード指定による再現可能なプレイ

### 作らない

- セーブとメタ進行
- 複数ステージ / フィールド
- イラスト素材 (色・記号・活字で見せる)
- 音響
- 実績・統計
- Electron パッケージング (余裕があれば最終日)

### 可視化について

デッキの食物網とピラミッドを常時 SVG で描き続ける画面が、このゲームの看板になる。
**「生態系の形が綺麗」が見て分かることが企画の前提**なので、これは削らずに初日から入れる。
スマートフォンの縦画面で成立させること。

## 9. 拡張の余地 (v1 では実装しない)

将来足すならここから、という順に並べてある。設計に穴だけ空けてある。

1. **生息地タグ** — `CardDef.habitat` (`forest` / `grass` / `water`) は
   型に含めてあるが、v1 では捕食判定に使わない。有効にすると
   「キツネは水辺のドジョウを食べられない」となり、生態系の専門化という
   デッキ構築の軸がもう1本増える。カード数が40を超えたら有効にする価値がある。
2. **供給のランダム化** — v1 は固定10種。リプレイ性は上がるがバランス調整の難度も上がる。
3. **レリック相当の常在強化** — 「保全政策」のような常在カード。
4. **複数フィールド** — 里山 / 池沼 / 河川。カード数が3倍必要になる。
